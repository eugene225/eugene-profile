Bookmarklet + Extension

Extension Guide

1) 확장 파일 다운로드

아래 버튼을 눌러 압축 파일을 다운로드하세요.

⬇️ Work Clock Extension

버전: v- · 업데이트: -

2) 설치 방법

Chrome에서 chrome://extensions → 개발자 모드 ON → 압축해제된 확장 프로그램 로드 클릭 → 다운로드한 zip 압축 해제 폴더 선택.

3) 단축키 설정

chrome://extensions/shortcuts에서 Work Clock의 단축키를 지정하세요. 기본 제안은 Alt+Shift+W입니다.
