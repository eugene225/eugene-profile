🕒 근무시간 계산기

🔍 empId 찾는 방법

개발자 도구를 사용하여 empId를 확인하세요:

  1. F12 키를 눌러 개발자 도구 열기
  2. Network 탭 선택
  3. '근로 시간 현황' 페이지에서 '검색' 버튼 클릭
  4. 버튼 클릭 시 "list?" 로 시작하는 API 요청 찾아서 클릭
  5. Payload 탭에서 empId 값 복사

💡 참고 empId는 한 번만 입력하면 자동으로 저장됩니다!

🚀 사용 방법

  1. 위의 버튼을 북마크바로 드래그
  2. 어느 웹페이지에서든 북마크 클릭 (1차 클릭)
  3. '근로 시간 현황' 페이지가 아니면 자동으로 바로 이동
  4. 페이지 로드 완료 후 북마크를 한 번 더 클릭 (2차 클릭)
  5. 근무 시간 계산 결과 확인!

💡 팁: Workplace 페이지에서 바로 실행하면 한 번만 클릭하면 됩니다!

⚠️ 주의: 빈 탭(새 탭)에서는 브라우저 보안 정책상 작동하지 않습니다.
👉 아무 웹사이트(예: 구글, 네이버 등)를 먼저 열고 북마크를 클릭하세요.

📊 계산되는 정보

  • 총 근무일: 이번 달 전체 근무일 (dayTpCd == 'WORK')
  • 오늘까지 근무한 시간: 실제로 일한 시간
  • 앞으로 근무해야 하는 시간: 총 근무일 × 8h - 근무 시간
  • 현재 초과/부족: 오늘 기준 초과/부족 시간
  • 오늘 포함 여부: 오늘 근무시간 자동 감지

empId 재설정

결과 화면에서 "empId 재설정" 버튼을 클릭하면 새로운 empId를 입력할 수 있습니다.

💡 저장된 empId를 변경하고 싶을 때 사용하세요!
